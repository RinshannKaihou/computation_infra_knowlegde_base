## 异步归因错位的证据边界

固定 commit 内的直接证据：框架分配器 OOM 为 host 侧同步抛出（分配路径可信）；执行层 GE OOM 在下发调用返回码上体现并最多重试 2 次；TASK_QUEUE_ENABLE 默认 1（异步下发默认开启）；统一错误文本 "NPU error, error code is …" 在检查点抛出（NPUException.cpp L224 附近）。**"OOM 或 device 错误报在与根因无关的位置"这一具体错位陈述在该 commit 代码中没有直接表述**，正文将其标为机制推断 + 待现场/日志证据，不作官方语义。
