## 缺口与冲突

- AMD 官方集群参考指南（文档号 63916）官方 URL 于 2026-10-09 返回 404；仅存在第三方镜像，未登记、不可用。AMD 侧 BMC 证据全部来自 OEM（Supermicro），这与"AMD 用具体 OEM BMC 作第三种映射"的验收口径一致，但意味着没有 AMD 官方对 BMC 行为的表述。
