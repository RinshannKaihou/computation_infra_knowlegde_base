## 缺口与冲突

1. **NIST 800-88 版本变更**：Rev.1（2014-12）已于 2025-09-26 撤回，Rev.2（2025-09）为现行版。任务书按 Rev.1 提出，本批以 Rev.2 取证；正文引用必须写 Rev.2。次级影响：Dell System Erase 技术说明与 KB 000186133 仍引用 Rev.1/IEEE 2883-2022，引用 OEM 文档时应注明其方法映射基于旧版 NIST。
2. **OEM 特定退役步骤部分未取得**：NVIDIA 侧无 DGX 整机退役/处置专门文档（DGX OS 7 重镜像的默认安装分支会重分区并重格式化 OS 与数据盘，另有显式「Without Reformatting Data RAID」保留分支；明示不动 MIG 设置与数据盘加密，文档未作 sanitization 合规声明——重镜像不是介质处置证据，不赋予 Clear/Purge 等级）；DGX 报废/回收仅有企业社会责任报告级泛泛表述，不登记。华为侧介质保留条款只有搜索片段（PDF 未取）。Supermicro 手册无数据擦除章节（只有 RMA 物流与保修限定）。整机级「退役安全步骤」目前只有 Dell System Erase（2020，14G）一条完整 OEM 证据。
3. **AMD 官方生命周期/RMA 文档未取得**：未找到 AMD Instinct 官方的返修/退役文档；AMD 侧证据以 Supermicro AMD EPYC 平台手册（MNL-2356）+ SuperBench 测试床（MI250X）代替，覆盖范围有限，正文不要外推到 MI300 代。
4. **NVIDIA RMA 流程页陈旧**：deploy/rma-process 为 Tesla 时代内容（nvidia-healthmon、portal.nvidia.com），无版本日期；与现行 DGX 流程（Enterprise Support 取 RMA 号、只用 NVIDIA 提供的替换件、旧件按随附包装退回）并存引用时须标注新旧。
5. **成本比较方法无官方 TCO 来源**：公开材料只提供构成要素——有效能力（MLPerf time-to-train、SuperBench「规格≠性能」与 repeatability 纪律）与运营成本（DGX SuperPOD 供电/散热预算）；官方单价、残值、维保价格均未取得。正文的容量/成本比较方法只能作为本库自建方法，用上述来源锚定各环节假设，不得写成某厂商推荐方法。
6. **SuperPOD 部署验证仅配置级**：bcm-validate-pod 核对软件版本/配置与规格一致，不含性能验收；且文档为 A100/H100 代（V16，2024-12-11），GB200 代对应文档未取。
7. **华为维护指南的角色定位**：指南面向华为/渠道工程师与企业管理员，更换操作含至少四人抬机、防静电、下电等现场要求；未含客户侧 RMA 物流流程，「返修」在华为侧主要靠服务合同（保修概览）而非单台手册。
