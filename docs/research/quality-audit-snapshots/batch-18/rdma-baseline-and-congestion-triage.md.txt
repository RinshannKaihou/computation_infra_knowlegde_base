# RDMA 网络基线、路由与拥塞诊断

## 目标与触发条件

当跨节点带宽低于预期、尾延迟抖动或集合通信出现超时症状，且需要先排除网络本身时，进入本流程。目标是给出"独立于 collective 的网络结论"：路径是否符合预期、拥塞证据是否存在、基线下降归哪一类。本流程只给判据，**不填执行结果**；只有文档证据时明确为来源整理。

## 适用范围与前置条件

- IB 子网与 RoCE 网络分开：IB 需 SM（每子网一个，`opensm.log`/`SUBNET UP`）、分区/PKey；RoCE 无需 SM，按 GID/MTU/路由/rail 记录前提。
- 观测来源：`ibv_devinfo`（max_mtu/active_mtu、IB 侧 lid、RoCE 侧 LID=0 正常）、`ibdev2netdev`、`ibtracert/ibdiagpath`（路径）、`ibroute`（转发表）；计数器只经 sysfs（`ports/*/hw_counters/` 与 `ports/*/counters`），RoCE 流量不进以太网计数器。
- OpenSM 路由引擎（minhop/updn/ftree/DOR 等）按拓扑选择，fat-tree 要求对称否则回退；file 路由忽略拓扑变化。
- 版本前提：perftest 两端**同版本同参**（不同版本可能不互通）；`--data_validation` 仅 `ib_write_bw/ib_read_bw`、RC、`tx_depth>=32`，与 `-a/post_list/run_infinitely` 等互斥。

## 需要的证据

| 证据 | 采集范围或定位 | 用途 | 缺失时如何处理 |
|---|---|---|---|
| 工具与版本快照 | perftest release+commit、NIC 型号/固件、链路 state/rate/width、NUMA 绑定、权限 | 口径可比性 | 缺失时不比较跨轮结果 |
| GID/路由快照 | GID 表、`cma_roce_mode`、VLAN/DSCP、LID/SM（IB）、`ibnetdiscover` 拓扑文件 | 区分 IB/RoCE 前提与路径 | 缺失时不做路由归因 |
| 计数器窗口 | UFM 口径 IB 表（Xmit/Rcv Data 4 字节单位、RcvErrors、XmitDiscards、XmitWait tick、Normalized 三项）、RoCE PFC/ECN 计数器 | 拥塞与错误判读 | 单位/方向未核对时不下结论 |
| 校验输出 | `--data_validation` 的 errors（仅 errors 为真问题；races/skips/retries 为信息性） | 正确性门禁 | 无 validation 轮时不判链路健康 |
| 链路掩盖声明 | FDR LLR 掩盖 symbol error（以 `ibdiagnet` LLR 重传率 500/s 为调查线，非 FDR 不套用） | 避免漏报 | 未查 LLR 时注明 |

## 步骤与判断分支

| 步骤 | 检查或动作 | 运行影响 | 预期证据与解释 | 下一步 |
|---|---|---|---|---|
| 0 | 建基线 G0：两节点（`ibnetdiscover` 存档），消息单点 + 全扫分开记，单流 `-q 1`，隔离无背景流，同口径三轮取 median，`errors=0` 才纳入基线 | 低：独占链路窗口 | 基线 median + 零增量计数器 | 进入对照组 |
| 1 | 消息维度 G1：小/中/大分档独立基线；`--report-cycles` 仅 latency 轮 | 低 | 各档独立基线；**不跨档比较"退化"** | 选档进入 G2 |
| 2 | 单流/多流 G2：`-q 1` vs `-q 4/8`，配 CQE 轮询批量记录 | 中：多流打满 | 多流增益；validation 轮结论限带宽对照 | 进入 G3 |
| 3 | 隔离/争用 G3：单流被测 + 可控背景流（第二对 QP/节点，不用推理负载冒充 RDMA 背景）；被测与背景 SL/GID/端口分开 | 高：背景流占用 | 争用轮仅与同争用基线比；拥塞以计数器增量为准，不以带宽差反推 | 进入 G4 或判读 |
| 4 | 多节点 G4：≥4 节点，单流逐对 + `ibroute` 快照；all-to-all-shift 仅作 `ibcongest` 静态分析输入 | 高 | 路径快照对齐计数器窗口 | 四分法判读 |
| 5 | 四分法：测试口径 / 路由映射 / 主机 / 真实网络 | 只读分析 | 口径差异解释、配置/映射原因、链路同期遥测+路径对齐、证据不足记 `unknown` | 满足完成判据后结束 |

计时口径（perftest README 方法框架，源码行号待固定 commit 重核）：CPU cycle counter 无上下文切换；latency 报 RTT 一半（非对称不准）；单向 BW 由 client 测量；latency 报 min/median/max（首值多为最大系 warmup）；`-D/-N/-H` 改变采样口径。NUMA：默认读 NIC NUMA 绑定线程+内存（`--pin_cores/--numa_node/--disable_numa` 互斥，外层 taskset 优先）；raw Ethernet 不支持 NUMA 选项。

## 停止条件与恢复安排

门槛是"何时停、何时恢复测试"的程序规则；触发后只允许回到隔离基线，不允许直接改 PFC/ECN/路由/SM 配置（配置变更属变更窗口，另行授权）。

| 信号 | 停止门槛 | 恢复门槛 |
|---|---|---|
| 正确性 | validation `errors>0`；或同窗口 `RcvErrors` 增量 | 查清同参后重跑隔离单轮 `errors=0` 且零增量，连续 2 轮 |
| 拥塞 | `XmitDiscards` 增量>0；或 pause storm 事件增量；或 ECN 标记率突变（相对自基线） | 暂停背景后增量回落基线带内、零增量，连续 3 采样窗 |
| 链路 | 任一 Downed 增量；或 LLR 率超 500/s（FDR 链路限定） | 事件清零后隔离单轮复测，速率/宽度一致且零增量 |
| 主机 | NUMA 绑定偏离或端口非 ACTIVE | 纠正后重建 G0 单轮基线点 |
| 方法 | 两端版本/参数不一致、基线缺失、清零未记录 | 结果记 `unknown`；补齐后重跑 |

完成判据（四选一）：(a) 口径差异解释；(b) 定位配置/映射原因并同口径复测确认；(c) 链路支路有同期遥测+路径对齐；(d) 证据不足记 `unknown` 并列缺失项。**"带宽回升"单独不算完成。**
