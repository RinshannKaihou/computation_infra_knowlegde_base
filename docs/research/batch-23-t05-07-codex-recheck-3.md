### 2.1 有效权重与实际贡献覆盖了原残留

E02 的加权公式和 E03 的实现分别说明：公平因子须乘以其优先级权重，再与其他有效因子合成作业优先级。E04 的 Raw Usage 定义涉及历史用量怎样记账，不能替代上述优先级贡献检查。P L105、L182 现在明确要求两类权重及作业级实际贡献，已经覆盖第二轮所指出的区别。

“`PriorityWeightFairshare` 等有效优先级权重”结合“A/B 作业的实际因子贡献”涵盖其他启用因子的影响，不必为关闭 C04 再增加一套穷举配置参数或现场命令。执行时仍须能审查这些实际贡献，不能把读取静态配置或取得 `sshare` 的 FairShare 值等同于已经满足该要求。E02 的 `sprio` 小节支持区分当前权重与逐作业优先级分解；本轮没有运行该工具，也不要求在设计文档中伪造其输出。

以下为**文本分支核验，不是实际作业试验**：

| 条件情形 | 当前门槛的处理 | 复核判断 |
|---|---|---|
| 有效权重或 A/B 实际贡献无法确认 | 属于 L105 的关键项缺失、L182 的要求未满足；不得据等待差异判公平策略 | 原缺证据分支闭合 |
| `PriorityWeightFairshare=0`，或公平因子没有有效贡献 | 两处均显式禁止据等待差异裁决该公平策略 | 覆盖第二轮反例；不宣称权重非零就一定有效 |
| 公平因子非零，但其他有效因子可能主导排序 | 必须审查 A/B 实际因子贡献，结合 L127 的多因子边界解释 | 不可把公平因子启用当成等待次序的充分解释 |
| 初态不可审查，或基线运行改变了历史状态 | L105 的降级门槛与 L125、L182 的历史/初态方案继续适用 | 没有因补权重而丢失顺序效应控制 |

这些要求是允许解释公平策略的必要门槛，不是对启动次序的充分因果证明。E02 的 Introduction 还说明抢占、预留和分区 PriorityTier 等会参与调度评估顺序；核验因子贡献不等于承诺“公平因子较高的作业必先启动”。当前修订没有新增这类保证。
