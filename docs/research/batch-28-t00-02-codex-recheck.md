## 新发现

### N01 · P2 · OPEN：新增比较表把机柜级供电散热直接写成跨柜共享

- **位置：正文 L122 超节点列**：“机柜供电散热为跨柜共享”。与初审哈希对应正文比较，该跨柜表述为本轮新增。
- **证据与问题：** [资源拓扑](../../knowledge/01-hardware/resource-topology.md) L179/L185 的 GB200 power shelf、bus bar 和 manifold 是所述机柜的组成；L278 明确区分单 tray 回路与机柜 manifold 假设。A3 L216/L218 也分别列单计算柜与总线设备柜的电源及散热组成，没有由“多柜超节点”推出这些机柜部件跨柜共用。设施级 rPDU/CDU 等是否被多个机柜共用，须按实际接线/供液成员核对，见[机柜供电散热的共享依赖方法](../../knowledge/01-hardware/rack-power-cooling-and-failure-domains.md)。当前没有支持该泛化的成员映射证据。
- **影响：** “影响待验证”只限制故障后果，不能让前半句的物理共用范围自动成立。某机柜受损也可能通过跨柜通信组影响应用，但那是传播后的应用范围，不等于机柜供电/散热部件物理上跨柜共享。混淆二者会把候选隔离组画错。
- **关闭条件：** 将机柜级部件限于其有证据的柜内共享组；更上层设施依赖若可能跨柜，另列 rPDU/CDU/供液等具体部件、实际成员与冗余前提，没有映射就写 unknown。互联也保留 L1 节点内、L2 跨节点/跨柜按组网核对的分层，避免把“交换结构/总线设备”整体压成同一范围。故障物理受损、通信组退化和应用影响继续分列；不需要为该修订执行故障注入。

N01 记录的是本轮新写入的共享拓扑范围错误；C01 记录的原故障传播必然性已撤回，两者不重复计数。本轮未确认其他需要独立 N 编号的新增问题；这不构成对关联页或其他批次的全量背书。
