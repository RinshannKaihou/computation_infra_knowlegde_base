## 缺口与冲突

- **docs.kernel.org 与固定 commit 的口径差**：既有登记 src.kernel.docs-cgroup-v2-2026-10-08 是动态 latest 页；本批以 v6.16 commit 重新核对并取得行号。两版在本批覆盖的字段（cpuset/memory/pids/device）内容一致，但正文引用必须以固定 commit 为准。
- **hiascend.com 页面可达性**：document/detail 动态页返回 cookie 墙（2026-10-09 观察），同内容的 doc_center/source 静态镜像可读。两条 MindCluster 文档（7.1.RC1 挂载表、7.2.RC1 FAQ）均经静态镜像取得；未比对两者是否逐字节一致，引用时保留静态路径与动态路径双记。
- **cgroup v1 与 v2 设备模型不可互换表述**：v1 devices 白名单有接口文件（devices.allow/deny），v2 无接口文件、完全靠 cgroup-BPF 程序（cgroup-v2.rst Device controller 节）。OCI spec 的 resources.devices 以 v1 语义描述、v2 下由运行时转换（spec Unified 节说明），因此「容器内枚举设备规则」在 v2 上没有可读的 cgroup 文件，诊断路径必须换 bpftool/运行时状态——本批未取 bpftool 文档，列为后续候选。
- **Ascend --kernel-memory 是 v1 时代 knob**：Atlas 200I A2 25.2.0 安装文档建议多容器配 --kernel-memory（依赖 kmem accounting）；cgroup v2 已废弃该 v1 特性（cgroup-v2.rst「Deprecated v1 Core Features」节），正文须按宿主 cgroup 版本分写，不可直接搬用。
- **Ascend 挂载表按产品分叉**：MindCluster 7.1.RC1 六张表覆盖 RC 场景模块/200I SoC A1/200I A2/500(3000)/500 A2/其他设备，310B 系多出 svm0、ts_aisle、vdec/vpc/pngd/venc 等 16 个管理设备（源码 addAscend310BManagerDevice 与之对应）；不存在「通用最小集」的官方说法，本库不提供万能挂载命令，与验收标准 3 一致。
- **NVIDIA Container Toolkit 文档无版本化快照**：docs.nvidia.com container-toolkit 为 latest 可变页；不可变对应物取 libnvidia-container 固定 tag（v1.20.1）。文档页自述的 CDI 已知限制（驱动移除、MIG 重配置不自动刷新）是「节点可见性过期」的厂商承认来源。
- **runc update 重置 device cgroup 的案例时效**：Ascend FAQ 基于 K8s 1.12/CentOS 7.6；机制（cpu-manager reconcile 触发 cgroup update）是否在新版 kubelet/runc 上仍存在未核证，正文只能作为「这类交互曾发生、需按现网验证」的历史案例引用。
- **AMD kfd 与 render node 的隔离粒度差**：/dev/kfd 为全 GPU 共享单节点（ROCm docker 页明言），按卡隔离落在 renderD 与运行时层；与 NVIDIA（per-GPU 节点 + caps）和 Ascend（per-chip davinciN + vdavinci 重命名）模型不同，三平台不可共用一张「设备节点—隔离」对应表。
- **设备 OOM 未在本批内核文档范围**：验收标准 1 的「设备 OOM 与物理内存/cgroup limit 分开判断」中，设备侧 OOM 的内核接口（如 KFD/amdgpu 显存压力）无对应内核文档条目；现有证据为已登记 src.vllm-ascend.issue-15920（NPU 分配失败案例）与 ROCm/驱动文档，设备 OOM 的系统级判据（对照 dmesg、驱动日志）建议另批取证。
- **/proc/\<pid\>/mountinfo 与 /proc/\<pid\>/cgroup 解析文档未单独取**：容器视角 cgroup 路径拼接依赖这两个文件，proc.rst 有 mountinfo 节（§3.5）但本批未逐字段核对，正文若写解析步骤需补核。
- **bpftool、eBPF 设备程序枚举工具链未取证**（见上 v2 条目）；psutil 等库未取证——按任务约定正文以工具无关的 /proc、cgroupfs 原始路径为准。
- **man7.org 镜像非版本化**：man 页以 colophon 的 man-pages 6.19 为固定口径，但 man7 是滚动镜像；如需不可变引用应改取 kernel.org 的 man-pages-6.19 tarball（本批未下载）。
