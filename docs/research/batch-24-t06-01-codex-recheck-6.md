### 3.2 组大小、步长与节点分布复算

本候选 `EDP = 64 / (ETP×EP×PP) = 64 / (2×4×1) = 8`。固定 `ep=e`、`etp=t`，只扫描 expert-DP 轴：

```text
G_EDP(e,t) = [16e + 2d + t | d=0..7]
e=0..3，t=0..1
node(16e + 2d + t) = 2e + floor((2d+t)/8)
                       = 2e + floor(d/4)
```

因此每组的 `d=0..3` 四成员在节点 `2e`，`d=4..7` 四成员在节点 `2e+1`。以下由审阅者使用 Python 标准库整数、集合与计数器独立枚举，没有导入或运行训练框架：

|---|---|---|---|
| 0 | 0 | `[0,2,4,6,8,10,12,14]` | 节点 0：`[0,2,4,6]`；节点 1：`[8,10,12,14]` |
| 0 | 1 | `[1,3,5,7,9,11,13,15]` | 节点 0、1，各 4 成员 |
| 1 | 0 | `[16,18,20,22,24,26,28,30]` | 节点 2、3，各 4 成员 |
