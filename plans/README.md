# 计划文件的生命周期

2026-10-22 起，知识库转入使用与按需维护阶段，当前以昇腾相关问题为主要使用场景。当前状态和开放项见[当前状态](../docs/current-status.md)，历史材料的使用方式见[归档说明](../docs/archive/README.md)。本目录采用原地逻辑归档：保留原路径与内容，通过文件头注释说明生命周期。

| 分类 | 文件 | 当前用途 |
|---|---|---|
| 历史冻结 | [首轮内容任务](content-backlog.yaml)、[第二轮内容任务](round-02-backlog.yaml)、[全覆盖任务](full-coverage-backlog.yaml) | 追溯原交付范围、验收、例外和证据，不作为当前写作队列 |
| 历史冻结 | [批次依赖](batch-dependencies.yaml) | 追溯原任务关系，不再驱动批次或并行波次 |
| 历史冻结 | [首轮来源池](source-acquisition.yaml)、[补充来源池](followup-source-acquisition.yaml) | 按需查找历史发现入口，不要求读完或采集全部项目 |
| 覆盖基线 | [主题覆盖盘点](topic-coverage.yaml) | 查询主题已有范围与缺口，需要时针对具体问题维护 |
| 未来可选、当前休眠 | [验证方案清单](validation-backlog.yaml)、[准备实例骨架](v00-preparation-instances.yaml) | 当前暂无实测环境，保留设计供今后具体需求取用，不启动执行 |

九份 YAML 仅新增生命周期注释，任务、验收、状态、证据及其他解析数据全部保留。`planned`、`collecting`、`in_progress`、`planned_new` 等历史值不构成当前待办或执行承诺；`done` 仍只表示当时约定的产物交付。旧模型、CLI 和批次约定保留为历史记录，本次归档不继续执行这些约定。

归档不关闭来源例外，也不把未知、部分覆盖、`not_ready` 或未执行改为已确认、已就绪或已复现。真实验证尚未完成的事实继续保留；覆盖基线用于了解内容范围，不要求为使用知识库先补齐所有验证。

出现具体问题时，先从[知识库首页](../README.md)或[昇腾入口](../paths/platforms/ascend.md)定位正文，核对其版本、来源和适用边界。需要补证据时再查本目录中相关的历史来源或单项方案；需要实际验证时，按该项需求重新确认环境、资源与已有授权范围。一次取用只覆盖具体问题，不恢复整套批次建设或验证排期。
