# 来源登记

[registry.yaml](registry.yaml) 登记外部资料的稳定 ID、入口、版本状态和许可范围。初始八项来自[调研备忘录](../research-memo-2026-09-29.md)；正文使用的具体版本另行登记，保留原有发现入口。来源原文不作为本库正文镜像。

- `registered_at` 表示登记时间，不表示最后一次网页抓取或实测时间。
- `revision: null` 表示尚未固定版本。项目首页可以作为导航来源；技术结论还需要在正文引用具体文档位置、版本或 commit。
- 固定 commit、发布版本文档和持续更新的网页具有不同稳定性。网页访问日期不能代替版本号；配套档案应说明引用所覆盖的范围。
- `license.status` 区分 `unknown`、`partial`、`identified`。即使根许可证已确认，也不覆盖外部引用或所有发行包。
- 新来源先登记 ID，再在内容的 `source_refs` 引用。来源 ID 存在只证明引用可解析，不证明它支持正文全部结论。

完整要求见[写作指南](../docs/authoring-guide.md)。本仓库自身的对外发布许可尚未决定，外部来源各自保留其许可和署名要求。
